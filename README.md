This project demonstrates the practical application of Python programming, data structures, file handling, object-oriented concepts, exception handling, data analysis, and visualization in a single menu-driven application.

Features
1. Student Registration & Grade Evaluation-
     Register students with personal and academic details.
     Automatically calculate grades and performance remarks.
2. Course Enrollment System-
     Enroll students in multiple courses.
     Manage course credits and enrollment limits.
3. Student Record Management-
     Store and display student information efficiently.
     Perform record operations using Python data structures.
4. Sorting & Searching Algorithms-
     Implement Bubble Sort for student ID sorting.
     Perform Linear Search and Binary Search operations.
5. Fee Management System-
     Calculate total student fees.
     Supports tuition, hostel, and transportation fee components.
6. File Handling Operations-
     Create, read, and process student records stored in files.
     Generate summary reports including average marks and top performers.
7. Directory Scanning with Exception Handling-
     Scan and display directory structures.
     Handle invalid paths and missing folders using custom exceptions.
8. Performance Analyser-
     Analyze student performance using NumPy and Pandas.
     Generate statistical summaries.
     Visualize results using Matplotlib charts.
